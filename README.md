# LILY CAKE 🍰

## 概要

「LILY CAKE」は、若者をターゲットにした架空のケーキ屋さんのWebサイトです。  
お店の紹介やメニューの閲覧はもちろん、オーダーメイドのケーキ注文や、期間限定のコラボ商品の確認も可能です。

韓国風のシンプルでやさしいデザインを意識し、かわいさとトレンド感を大切にしました。

## 使用技術

- GitHub

## 主な機能・特徴

- 商品メニューの閲覧
- スライダー
- ケーキのオーダーメイド受付フォーム
- お問い合わせフォーム
- 送信完了メッセージ
- 商品への「いいね」機能
- Instagramへの遷移
- ホバー時の傾きアニメーション

---

## 工夫した点・こだわり

- 全体的に淡いカラーと角丸を使用し、やさしくて可愛らしい印象を演出しました  
- 「送信完了メッセージ」を表示し、フォーム操作の安心感を高めました  
- 「いいね」機能によって、お気に入りのケーキを視覚的に表現できるようにしました  
- ケーキ画像にホバーすると少し傾くアニメーションで、動きのある楽しく、可愛いUIにしました  
- 韓国語と日本語を混ぜることで、韓国らしさや世界観を表現しています  
- 全体のデザインを派手にしすぎず、シンプルにまとめることで韓国っぽさを演出しました

---

## 改善点・今後の課題

- コード構造の整理が不十分で、特にレスポンシブ対応には課題が残りました 
- 作業の効率が悪く、構造が整理されていない部分がある  
- 「トップに戻る」ボタンなど、ユーザーの導線をより分かりやすくしたい  
- 「いいね」したケーキをローカルストレージやデータベースに保存できるようにしたい
